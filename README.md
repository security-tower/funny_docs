# `funny_docs`
`funny_docs` is a repository of only (very very very very very)
funny documents, such as news reports, "facts", letters, and the like.

Example:
```
Did you know that in 1654, Abraham Lincoln invented Wi-Fi? It was kept secret by a group of antarctic scientists until it was "invented" in 2025?
```
> [!NOTE]
> None of these are real.
